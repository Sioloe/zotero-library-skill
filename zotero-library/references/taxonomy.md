# 分类规则

先检查用户已有目录和标签，保留含义清晰的术语。默认中文主题标签，方法和工具保留通行缩写；同义词统一，例如“大语言模型”和“LLM”选其中一种，而不是两个都加。不要预先套用机器学习等特定学科。

建议目录最多 2–3 层，优先沿用原目录。没有既有体系时可采用：

| 顶层分类 | 用途 |
| --- | --- |
| 00 待整理 | 信息不足、等待复核的文献 |
| 10 研究主题 | 从实际文献归纳主题，按需要建立子分类 |
| 20 综述与基础 | 入门综述、理论背景、基础方法 |
| 30 方法与工具 | 可复用的实验方法、分析方法、软件与数据资源 |
| 40 应用与案例 | 特定任务、行业、场景或案例 |

只创建确实有文献归属的目录。主题与用途可以交叉分类；单个条目通常 1–3 个适用分类，避免为每篇文献创建一个文件夹。

标签采用可检索的维度，例如 `主题/医学影像`、`方法/随机对照试验`、`类型/综述`、`应用/临床诊断`。每篇通常新增 3–6 个有依据的标签，不为凑数量生成标签。

`状态/待读`、`状态/在读`、`状态/已读` 只根据用户描述或既有记录设置；不能根据有无笔记猜测是否已读。已有状态标签时不再自动添加相反状态。

优先级仅针对用户的阅读目标：`优先级/P1`（建议先读）、`优先级/P2`（后续深入）、`优先级/P3`（补充参考）。不能从期刊名称推断质量，也不能编造引用量、影响因子。没有具体研究目标时优先给出“综述→基础→主要方法→应用→最新进展”的建议清单，并解释依据；不强制给整库加优先级标签。

默认接受有明确标题／摘要证据且置信度不低于 0.8 的分类建议。置信度是助手主观判断，不是校准概率。低置信度建议写入计划的 review 列表，不自动写回。只有标题时使用较宽主题，不猜测具体数据集、技术细节或实验结论。

阅读清单应包含：顺序、原始标题、作者／年份、主题、建议优先级、先读理由、证据来源。可输出 CSV 或 Markdown；顺序留在清单中，不冒充 Zotero 的原生排序字段。
